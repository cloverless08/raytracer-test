# Ray Tracer Test

This is a research project made concurrently with my CSC1060 Capstone black hole sim
to enable to me learn and implement the ray tracer required before applying it to my project.

This project largely comes from the "Ray tracing from scratch [C++ & SLD2]" Youtube series by @QuantitativeBytes, and my own research as described in the
black hold ism documentation.

While this project comes from lessons and tutorials, my implementation into the simulation comes from my own
understanding of the princicples and methods that I learned while coding this.

As is standard practice with my projects and to uphold my academic integrity,
no generative AI was used in this project.
